# x86 系列后端

x86 系列后端是 Gaia 框架中最底层的后端之一，支持直接生成 32 位 (x86) 和 64 位 (x86_64) 架构的机器指令码（Opcode）。

## 主要特性

- **多架构支持**: 统一的接口支持 x86 (IA-32) 和 x86_64 (AMD64) 指令集。
- **直接代码生成**: 不经过任何中间汇编器，直接输出二进制机器码。
- **寄存器分配**: 针对不同模式（32位 vs 64位）自动化的寄存器分配策略。
- **指令集支持**:
  - 基础 x86/x86_64 指令集
  - SSE/AVX/AVX-512 扩展支持
  - 原子操作指令 (LOCK 前缀等)
- **ABI 兼容性**: 
  - **64位**: 支持 System V ABI (Linux/macOS) 和 Microsoft x64 ABI (Windows)。
  - **32位**: 支持 cdecl, stdcall, fastcall 等多种调用约定。
- **内联汇编**: 允许在高级代码中无缝嵌入原生指令。

## 使用场景

- **高性能计算**: 需要极致性能的数学运算或数据处理。
- **系统编程**: 编写内核、驱动程序或引导加载程序。
- **旧系统兼容**: 针对 32 位遗留系统的开发与维护。
- **JIT 编译**: 作为即时编译器的基础后端，动态生成执行代码。

## 示例代码

```rust
// x86 系列指令生成示例
use x86_64_assembler::X86_64Assembler;
use gaia_types::helpers::Architecture;

// 创建 64 位汇编器
let asm_64 = X86_64Assembler::new(Architecture::X86_64)?;

// 创建 32 位汇编器
let asm_32 = X86_64Assembler::new(Architecture::X86)?;
```

## 注意事项

使用 x86 后端需要开发者对硬件架构有较深的理解。生成的代码是高度平台相关的。虽然 x86_64 处理器通常兼容 32 位代码，但反之则不然。
